# 05 — 交易风控规则目录

> **策略映射约定**（相对原型）：订单级规则**不使用**「人工审核」。原「人工审核」改配为下表「生产策略」列。  
> **商户级**「人工审核」仅用于商户监控、入网，见 §商户监控。

原型共 **42 条** 编号规则。多规则命中：取最高风险等级 + 优先级最高的**交易级**策略（商户级规则走独立 job）。

---

## 策略 scope 说明

| scope | 执行方式 | 人工审核 |
|-------|----------|----------|
| 交易级 | evaluate 同步返回 pass/decline/challenge_3ds | 无 |
| 商户级 | 聚合检测 → 暂停交易/结算 → 商户预警 | **有**（商户人工审核） |

## STR 默认推送规则

默认对以下 **类别** 或 **风险等级** 启用 STR 推送：

- **类别**：欺诈行为、地理与制裁、黑名单、商户监控
- **风险等级**：高风险、极高风险
- **LTR**：USD ≥ 10000，HKD ≥ 50000（可配置）
