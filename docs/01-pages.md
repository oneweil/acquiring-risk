# 01 — 页面清单

## 菜单结构

```
监控中心
  ├── 风控总览      dashboard
  ├── 订单监控      order
  └── 预警中心      alert
商户管理
  ├── 商户列表      merchant          [原型另有「商户入网」onboarding，当前侧栏未展示]
  ├── 商户风险等级规则  merchant_risk_level
  └── 商户评估规则  merchant_risk
合规报送
  ├── STR 报送      str_report
  ├── STR 推送规则  str_push_rule
  └── EDD 强化尽调  edd
规则配置
  ├── 风控规则      rule
  ├── 处置策略      disposition
  └── 黑名单        blacklist
系统管理
  ├── 用户管理      user
  ├── 角色权限      role
  └── 日志记录      audit_log
```

## 页面明细

### 监控中心

#### 1. 风控总览 `/admin/dashboard`

| 项 | 说明 |
|----|------|
| 优先级 | P2（依赖订单/预警有真实数据后再接） |
| 原型 ID | `dashboard` |
| 实现状态 | 已完成 UI + Mock JS |

**KPI（8 项）**

- 今日交易笔数、今日交易金额(USD)、待处理预警、拦截率
- 待审商户、活跃商户数、高风险订单、3DS 验证率

**区块**

- 实时订单流（约 4s 刷新，跳转订单监控）
- 今日风险分布（低/中/高占比饼图）
- 最新预警表（Top 5，可打开人工审核弹窗）

**操作**

- 顶栏「待处理预警」角标（与预警中心联动，尚未实现）

|----|------|
| 优先级 | **P0** |

#### 3. 预警中心 `/admin/alert`

| 项 | 说明 |
|----|------|
| 优先级 | **P0** |
| 原型 ID | `alerts` |
| 实现状态 | 占位页 |

**分两类展示（正式方案）**

1. **交易预警**：命中规则的记录/调单跟进，**不代表订单挂起待审**
2. **商户预警**：交易量暴涨/暴跌等 → **商户人工审核**队列

**筛选**

- 预警类型（交易 / 商户）
- 风险等级、状态（待处理/处理中/已关闭）、处置策略

**商户预警列表列（建议）**

预警编号、时间、商户号、商户名称、触发类型（暴涨/暴跌/…）、指标摘要、是否已暂停交易/结算、状态、操作

**交易预警列表列**

预警编号、预警时间、商户号、订单号、金额、风险等级、规则名称、处置策略、状态、STR 报送、操作

**弹窗**

- 交易预警：调单上传、关闭（**无「订单审核通过/拒绝」**）
- 商户预警：审核通过（恢复交易+结算）/ 维持暂停 / 误报关闭

#### 9. 处置策略 `/admin/disposition`

| 项 | 说明 |
|----|------|
| 优先级 | **P0** |
| 原型 ID | `disposition` |

**内置策略（9 种，按 scope 区分）**

| 编码 | 名称 | scope | 阻断交易 | 推送预警 | 说明 |
|------|------|-------|----------|----------|------|
| DECLINE | 拒绝交易 | 交易级 | 是 | 是 | evaluate 同步 decline |
| 3DS_CHALLENGE | 3DS强验 | 交易级 | 否 | 是 | evaluate 返回 challenge_3ds |
| ALERT_ONLY | 仅预警 | 交易级 | 否 | 是 | pass + 记录预警 |
| CHARGEBACK_INQUIRY | 调单 | 交易级 | 否 | 是 | 事后调单，**不挂起订单** |
| DELAY_SETTLE | 延迟结算 | 交易级 | 否 | 是 | 标记延迟，非待审 |
| LIMIT_AMOUNT | 限制单笔额度 | 交易级 | 否 | 是 | |
| WATCHLIST | 加入观察 | 交易级 | 否 | 是 | |
| SUSPEND_MERCHANT | 暂停收单 | 商户级 | 是 | 是 | 拒绝新单 |
| PAUSE_SETTLEMENT | 暂停结算 | 商户级 | 否 | 是 | 冻结打款 |
| MERCHANT_MANUAL_REVIEW | 商户人工审核 | 商户级 | — | 是 | 配合暂停交易/结算，**非订单挂起** |

> 原型中的 `MANUAL_REVIEW（人工审核）` 在正式方案中拆为：**交易级**用拒绝/3DS/仅预警替代；**商户级**用 `MERCHANT_MANUAL_REVIEW` + 暂停交易/结算。

**列表筛选**：风险等级、作用域（交易级/商户级）、状态

**列表列**：优先级、策略编码、名称、说明、风险等级、作用域、是否阻断、推送预警、状态、操作

**附加**：今日策略触发统计 KPI
