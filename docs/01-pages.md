```
监控中心
  ├── 风控总览      dashboard
  ├── 订单监控      order
  └── 预警中心      alert

  ├── 商户列表      merchant          [数据源：本地 risk_merchant 投影；入网审核不在本系统]
  ├── 商户风险等级规则  merchant_risk_level
```

## 页面明细

### 监控中心

#### 1. 风控总览 `/admin/dashboard`

| 项 | 说明 |
|----|------|
| 优先级 | P2（依赖订单/预警有真实数据后再接） |
| 原型 ID | `dashboard` |
| 实现状态 | UI + Mock JS（KPI + 决策/预警分布 + 实时订单流 + 规则/商户 + 预警表） |

**区块（自上而下）**

1. **顶栏 KPI**：今日评估笔数、今日评估金额(USD)、待处理预警、待确认 STR、临期/逾期 EDD 等
2. **今日决策健康度 + 预警风险分布**：决策三态 donut；预警低/中/高/极高 donut
3. **实时订单流**：约 4s 刷新 Mock 流，决策为 `pass` / `decline` / `challenge_3ds`（跳转订单监控）
4. **风险从哪来**：今日 Top 命中规则；今日风险集中商户
5. **最新待处理预警**：Top 8（跳转预警中心）

**不做**

- 待审商户 / 入网审核队列
- 订单挂起「人工审核」语义

|----|------|

**弹窗：订单详情**

- 基本信息、卡信息与持卡人、风控结果（含 STR 入口、跳转预警）
- 操作：关闭、创建/查看 STR、发起审核/取消拦截

#### 3. 预警中心 `/admin/alert`

| 项 | 说明 |
|----|------|
| 优先级 | **P0** |
| 原型 ID | `alerts` |
| 实现状态 | **交易预警已实现**；预警一律挂订单，**不建**商户预警人审表 |

**展示约定**

1. **交易预警**（唯一）：命中规则的记录/调单跟进，**不代表订单挂起**；处置**不改变**订单授权终态；`order_no` 必填
2. ~~商户预警人审队列~~：**不做**；放量等走商户状态动作 + 订单预警跟进

**筛选（交易预警）**

- 风险等级、状态（待处理/处理中/已关闭）、处置策略
- 无 status 筛选时默认排除「已关闭」（与原型一致）；显式选已关闭可查

**交易预警列表列**

预警编号、预警时间、商户号、订单号、金额、风险等级、规则名称、处置策略、状态、STR 报送、操作

**弹窗（交易预警）**

- 调单：上传材料、提交材料维持处理中、调单完成关闭、误报关闭
- 默认/仅预警等：关闭预警、误报关闭
- **无**「订单审核通过/拒绝」「取消拦截」等改订单态操作

#### 9. 处置策略 `/admin/disposition`

| 项 | 说明 |
|----|------|
| 优先级 | **P0** |
| 原型 ID | `disposition` |

**内置策略（8 种；无订单挂起人审）**

| 编码 | 名称 | scope | 阻断交易 | 推送预警 | 说明 |
|------|------|-------|----------|----------|------|
| DECLINE | 拒绝交易 | 交易级 | 是 | 是 | evaluate → `decline` |
| 3DS_CHALLENGE | 3DS强验 | 交易级 | 否* | 是 | evaluate → `challenge_3ds` |
| ALERT_ONLY | 仅预警 | 交易级 | 否 | 是 | `pass` + 写订单预警 |
| CHARGEBACK_INQUIRY | 调单 | 交易级 | 否 | 是 | 事后调单，不挂起订单 |
| DELAY_SETTLE | 延迟结算 | 交易级 | 否 | 是 | 标记延迟，非待审 |
| WATCHLIST | 加入观察 | 交易级 | 否 | 是 | |
| LIMIT_AMOUNT | 限制单笔额度 | 商户级 | 否 | 是 | 商户侧限制，非人审队列 |
| SUSPEND_MERCHANT | 暂停收单 | 商户级 | 是 | 是 | 改商户状态；新单 decline |

> `*` 3DS 不记 `is_block`，由策略码映射 `challenge_3ds`。原型 `MANUAL_REVIEW` **不入库**；原绑人审的规则种子映射为 `ALERT_ONLY`（或运营改绑拒绝/3DS）。
>
> `scope=merchant`：商户状态动作，**不是**人工审核工单表。**不建** `MERCHANT_MANUAL_REVIEW` / `merchant_alert`。
>
> 风险等级枚举统一：`low` / `mid` / `high` / `critical`（不用 `medium`）。
**列表筛选**：风险等级、作用域（交易级/商户级）、状态

**列表列**：优先级、策略编码、名称、说明、风险等级、作用域、是否阻断、推送预警、状态、操作

**附加**：今日策略触发统计 KPI
